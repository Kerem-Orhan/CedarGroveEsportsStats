Team sign-in

Team members post results by saving them to the site's GitHub repository. You need a GitHub access key with permission to edit it.

  1. Open GitHub → new fine-grained token.
  2. Under Repository access, pick only CedarGroveEsportsStats.
  3. Under Permissions → Contents, choose Read and write. Generate it and paste it below.

The key stays in this browser only. Sign out on shared computers.
